# 🕐 Digital Clock

A modern and responsive **Digital Clock** built using **HTML, CSS, and JavaScript**.

The clock displays the current time dynamically in real time, with the hours, minutes, and seconds continuously updating.

## 🌐 Live Demo

👉 **[Visit Digital Clock](https://aryanh12345.github.io/Digital-Clock/)**

## 🚀 Features

- 🕐 Displays the current time in real time
- ⏱️ Continuously updates hours, minutes, and seconds
- 📱 Responsive design
- 🎨 Clean and modern user interface
- ⚡ Lightweight and fast
- 💻 Built using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling and responsive design
- **JavaScript** – Real-time clock functionality
